项目简介

本作品实现了一套基于SDN 的智能DDoS 攻击检测与防御系统——Goku。Goku智能DDoS检测防御系统结合SDN架构与深度学习技术，拟实现一个易用，可靠，具备轻量级、智能化DDoS攻击检测与防御能力的SDN防御系统。本系统对传统入侵检测、SDN和深度学习技术的综合利用，研究传统网络功能在SDN架构下的实现，利用深度学习模型潜在的决策优势与SDN易于部署、计算资源集中、能与复杂网络环境互动，动态调整网络策略的优势相结合，探索动态、智能、交互式网络管控的新思路。

主要特点

智能化检测

采用尖端的深度学习算法，Goku能够进行多维度流量分析，不仅精准识别已知的DDoS攻击模式，更能通过持续学习适应不断演变的攻击手法（如ACK Flood, UDP Flood, ICMP Flood等多种类型攻击），有效降低误报率与漏报率，保障业务在复杂攻击下的连续性与稳定性。

SDN灵活性

借助SDN架构的集中控制与可编程特性，Goku实现了对网络资源的精细化管理与动态调度。系统能够根据实时网络态势，秒级下发和调整防御策略至底层网络设备，实现流量的智能引流、清洗与路径优化，从而迅速隔离攻击流量，最小化攻击对正常业务的影响范围。

轻量易用

Goku系统在追求强大功能的同时，兼顾了部署的便捷性与资源的高效利用。其轻量化设计确保了在各类网络环境中的低资源占用，对硬件要求不高。配合直观易用的Web管理界面，极大简化了系统的配置、监控、日志审计与维护流程，降低了运维门槛。

可靠防御

Goku提供了一套从流量捕获、特征提取、智能检测到自动响应的闭环式自动化防御机制。系统通过实时监控与智能分析，确保在攻击发生初期即可快速介入，形成多层次、高可靠的纵深防御体系，能够有效抵御大规模、高并发的DDoS攻击，全方位守护网络核心资产安全。

关键模块

该系统包括三个关键模块：

  • 基于Ryu控制器的SDN防火墙： 负责执行防御策略，通过OpenFlow协议修改网络交换机流表项，对恶意流量进行精确丢弃或限速转发。
  • 基于深度学习的IDS技术构建的DDoS入侵检测器： 采用CNN与GRU等深度学习模型，实时监控与分析网络流量，智能识别各类DDoS攻击模式，并将检测结果上报。
  • 基于Django的管理系统： 提供图形化的Web端管理页面，方便用户查看实时网络流量状况、设备状态、管理防火墙规则、配置入侵检测策略以及审阅告警日志。

设计思路

我们的系统主要由三大模块构成：SDN 防火墙、DDoS 攻击检测器以及管理系统。这三大模块协同工作，构成一个完整的防御体系：

  • SDN 防火墙是系统核心模块，通过修改交换机流表项提供基本的网络控制能力。它配合交换机应用防火墙策略，并将实时流量镜像一份至DDoS 攻击检测器供后者分析。
  • DDoS 攻击入侵检测器以深度学习模型的形式部署，对捕获的流量进行实时分析，并将分析结果（如识别到的攻击类型、攻击源等）传递给SDN 防火墙，辅助防火墙进行决策和策略更新。
  • 管理系统主要面向系统中的日志、DDoS 入侵检测规则以及防火墙规则这三类重要文件。它向用户提供直观的日志查看功能和便捷的路由规则编辑界面，方便管理员监控系统状态和调整防御策略。

技术路线

本作品的实现主要依赖以下技术栈：

  • 编程语言与环境： 选用 Python 3.x 语言作为主要的开发语言，并在 Linux (Ubuntu/CentOS) 环境下进行开发和部署。
  • SDN核心组件： 使用 Mininet 网络仿真器（版本2.3.0+）进行网络环境的搭建与测试，采用 Ryu 控制器 (版本4.x) 作为SDN控制器来实现防火墙功能，为系统提供核心防护能力。
  • DDoS检测模型： 选用卷积神经网络（CNN）与门控循环单元（GRU）相结合的深度学习模型，利用 TensorFlow/Keras 框架进行训练与部署DDoS 入侵检测器，旨在为系统提供高效、准确的实时流量分析检测能力。
  • 管理系统框架： 选用 Django (版本3.x/4.x) 作为后端Web框架，并结合 Bootstrap 5 前端框架来快速实现管理系统，致力于提供一个易用实用、响应式且简洁明了的Web端管理界面。

设计方案

系统各模块间的交互与核心功能实现如下：

  • SDN防火墙与交换机通信： SDN 防火墙通过南向接口（SBI）协议与网络中的交换机进行通信，具体采用 OpenFlow 1.3 版本作为通信协议标准。
  • 流量镜像与规则下发： SDN 防火墙能够读取预设的防火墙规则文件。根据这些过滤规则，为进入网络的数据报文构造相应的流表项，并将这些流表项下发至交换机。同时，指示交换机将相关流量额外转发一份镜像数据报文到DDoS 入侵检测器，以供分析。
  • 入侵检测与反馈： DDoS 入侵检测器实时保持监听状态，对从交换机捕获的数据报文进行深度检测与分析。一旦检测到可疑攻击行为，会将检测结果（例如攻击类型、源IP、目标IP等信息）通过REST API或消息队列等方式发送至SDN 防火墙。
  • 动态策略更新： SDN 防火墙根据从DDoS 入侵检测器接收到的检测结果，动态地对防火墙规则进行相应更新，例如添加新的阻止规则或修改现有规则，以应对新出现的威胁。
  • 管理系统功能： 管理系统为用户提供了对防火墙规则和入侵检测规则的在线编辑界面，使得管理员可以方便地调整和优化防御策略。同时，系统还支持查看实时报警信息日志、历史攻击数据统计与可视化图表，帮助管理员追踪安全事件和评估系统性能。

应用场景

我们的系统主要面向SDN 网络架构中的DDoS 防护问题，为此我们采取入侵检测系统、防火墙以及SDN控制器联动的方式来防御DDoS 攻击。入侵检测系统使用AI 技术，智能检测网络流量中的恶意流量，将检测结果发送给防火墙。防火墙根据入侵检测系统的告警信息生成防火墙规则，然后SDN 控制器根据防火墙规则下发相应流表到交换机，阻断SDN 网络与攻击者之间的流量，实现对DDoS 攻击的防御。我们还实现了DDoS 防御系统的Web 端管理页面，可以查看网络中的流量状况、增删改查防火墙与入侵检测规则等。
